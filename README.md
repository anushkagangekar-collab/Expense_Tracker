# 💰 Expense Tracker

A simple and beginner-friendly **Expense Tracker Web Application** developed using HTML, CSS, and JavaScript.

This project helps users manage their income and expenses, check their balance, view transaction history, and generate simple expense reports.

---

## 📌 Project Description

The Expense Tracker allows users to:

- Add income
- Add expenses
- Select expense categories
- View total income
- View total expenses
- Calculate available balance
- View transaction history
- Delete transactions
- View expense reports
- Store data using Browser Local Storage

---

## 🚀 Features

### 🏠 Home Page
- Introduction to the Expense Tracker
- Easy navigation
- Quick access to Dashboard and Add Expense

### 📊 Dashboard
- Total Income
- Total Expense
- Available Balance
- Recent Transactions

### ➕ Add Expense
- Transaction Name
- Amount
- Transaction Type
- Category
- Date
- Add Transaction button

### 📜 Transaction History
- View all transactions
- Income and expense details
- Delete transactions

### 📈 Reports
- Total Income
- Total Expense
- Available Balance
- Total Transactions
- Category-wise Expense Report
